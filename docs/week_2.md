## 08-15 (토) — 방향 확정: 학습 레시피로 CNN을 밀고 뒤에 LM을 붙인다

**목표를 판정 가능한 숫자 둘로 옮겼다.** 주장은 "파라미터·학습비용을 훨씬 덜 쓰고 213M 단독과
동급 이상"이다.

- **성능선 = post-LM MAE ≤ 0.3955 nm** (skip-MLP 단독). 현재 0.6110, 천장 0.3336.
  오차 구조가 `post-LM ≈ 0.33 + 분지실패율 × 약 40 nm`이므로(십분위 1~9가 0.25~0.47로 평평,
  10분위만 3.205) **목표는 CNN MAE가 아니라 분지 실패율 0.67% → 약 0.15%다.** run마다
  5,000행에 LM을 붙여 실패율로 판정한다.
- **자원선은 세 미터로 나눠 잰다**: 파라미터·크기(322배 유리) · 학습 비용(에폭당 12.0초 vs
  119.6초) · 추론 지연. 앞의 둘은 이미 이기고 있었고 **지연만 지고 있었다** → 오늘 그 자리를
  고쳤다(아래).
- **용량은 유지하거나 조금만 늘린다** — 예산·레시피가 먼저다. 근거는 과소적합이 측정돼 있다는
  것이다: CNN은 `train_l1` 2.1943 / val 2.3455(격차 0.151)이고 skip-MLP는 0.1529 / 0.3955다.
  둘 다 **best 에폭이 마지막이고 lr이 0으로 소진돼** 끝났다.
- **비교 대상은 213M 단독으로 고정한다.** 213M에 같은 LM 보정을 붙이는 대조는 하지 않기로
  했으므로, "큰 모델에도 붙이면?"은 **측정하지 않은 열린 질문**으로 리포트에 남긴다.

### 추론 지연 레버 — 해석적 야코비안 + 조기 종료

디코더가 미분가능한데 역해가 중앙차분을 쓰고 있었다. M_j = cos δ_j·I + i sin δ_j·K_j 이고
K_j² = I 이므로 **dM_j/dd_j = i·k_j·K_j·M_j** 다. 접두 곱과 접미 벡터를 한 번씩 모으면
cos/sin을 다시 계산하지 않고 L개 열을 전부 얻는다 (`tmm_reflectance_jacobian`).

- **측정 (로컬 WSL2 CPU 8스레드, holdout 4,096행)**: LM 30회 c128이 11.764 → 3.638(해석적,
  3.23배) → 1.618(+조기종료, 7.27배) → c64에서 1.084(**10.85배**) ms/행. **MAE는 0.6752로
  전부 동일하다.** `cnn+LM` 합계가 12.060 → 1.380 ms/행이라 skip-MLP 대비 **5.53배 손해에서
  0.63배(1.6배 유리)로 뒤집힌다.**
- **🔴 조기 종료 기준을 잘못 잡으면 정확도를 잃는다.** 기각된 스텝을 이동 0으로 세니 MAE가
  +0.0093 nm 나빠졌다 — 감쇠가 오르며 스텝이 되살아나는 LM 특성 때문에 어려운 행이 잘린다.
  **제안된 스텝 폭**으로 판정하니 대가가 0이 됐다.
- **🔴 부수 소득 — dtype 흔들림이 사라진다.** c64 중앙차분은 MAE 0.6503으로 c128(0.6752)과
  다르다. 보폭 1e-3 nm가 상대 섭동 1e-5라 float32 유효자리(1.2e-7)를 먹기 때문이고, 이 표본에서
  낮게 나온 것은 메커니즘이 아니라 우연이다. 해석적 경로는 c64가 c128과 같은 값을 준다.
- **🔴 R을 접미 벡터에서 만들면 forward와 비트가 어긋난다** (곱 순서가 반대). LM이 두 경로의 R을
  같은 잔차 장부에 섞어 쓰므로 **접두 곱에서 만들어** 비트 동일을 테스트로 걸었다.
- 정확성은 **autograd로** 검증한다(상대오차 1.2e-14) — 유한차분은 절단오차가 있어 참조값이
  못 된다. 물리 테스트 8번으로 고정, L=1 경우도 따로 건다(접두 곱이 항등이라 순서 버그가
  안 드러난다).
- **기본값은 `jacobian="fd"`·조기 종료 off로 두었다** — 커밋된 리포트가 그 설정으로 나왔으므로
  기본값을 바꾸는 커밋에서 `inversion_refine.md`·`stage_a_gate.md`를 함께 재생성한다.
- 정본 표에는 CPU와 GPU 절이 함께 있어야 하므로 **로컬 단독 실행으로 덮으면 GPU 절이 사라진다**
  → 자주 쓰는 명령에 `--out`을 박았고, GPU 정본은 Colab 재실행 대상이다.
