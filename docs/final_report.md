# FringeNet 최종 보고서

**Physics-informed deep learning for thin-film thickness metrology** — 2026-08-08 ~ 08-20 (3주).

이 문서 하나로 프로젝트의 취지·흐름·결과를 파악할 수 있게 쓴 최종 취합이다. 루트
[README](../README.md)보다 한 층 깊게, 단 **최종 결과로 이어지는 결정 사슬만** 다룬다 —
개별 실험의 전체 상세는 [reports/](../reports/README.md)의 리포트 8편, 날짜별 연표는
week_1·week_2가 정본이고, 본문의 모든 수치는 그 정본에서 복사한 실행 산출물이다.

## 1. 취지 — 무엇을, 왜

**문제**: 반사율 스펙트럼(226채널)으로부터 4층 박막(SiN/SiO₂/SiN/SiO₂ on Si)의 두께[nm]를
역산한다. 실제 fab의 비파괴 박막 계측(reflectometry)과 같은 구조다 — 두께 → 스펙트럼의
순방향은 물리 모델(TMM)로 정확하고 빠르지만, 역방향은 해의 다중성(같은 관측을 설명하는
여러 fringe 분지) 때문에 어렵다. 데이터는 데이콘 대회의 train 81만 행(두께+스펙트럼) /
test 1만 행(스펙트럼만), 지표는 층별 MAE.

**목표**는 리더보드 순위가 아니라 셋이었다: ① 물리 단위 테스트를 통과한 미분가능 TMM
forward 모델 ② 물리 결합의 기여를 ablation으로 정량화 ③ 재현 가능한 코드와 읽히는 문서.
비교 기준은 남의 점수가 아니라 **직접 재현한 리더보드 1위 단일 모델**(213.2M skip-MLP,
holdout MAE 0.3955 nm — [strong_baseline.md](../reports/strong_baseline.md))로 세웠다.

**결과 한 줄**: 1.52M 파라미터 파이프라인(경량 CNN + 물리 보정)이 holdout 0.3396 /
**리더보드 test 0.33895 nm (4위)** — 213M 단독 대비 격자 밖 실전 조건에서 **−29%**.

## 2. 토대 — 데이터에서 확정한 세 가지 사실

이후 모든 설계·판정이 이 셋 위에 서 있다 ([eda_notes.md](../reports/eda_notes.md) ·
`scripts/verify_data.py`).

1. **노이즈는 σ = 0.008658의 가산 노이즈이고, 균등분포에 가까우며, 유계다(|ε| ≤ 0.0152).**
   물리적으로 불가능한 음의 반사율(행의 46.9%)이 노이즈의 증거이고, 1.83억 관측에서
   R < −0.0152가 0건이라 유계가 확정된다. 파급 둘 — 완벽한 forward 모델도 재구성 RMSE가
   σ 아래로 못 내려가므로 판정 기준을 노이즈 바닥 대비 상대값으로 잡아야 하고, **유계
   상한을 넘는 잔차 하나하나가 통계 없이 모델 오류의 증거**가 된다(가장 날카로운 잣대).
2. **train 두께는 10 nm 격자의 전수 조합(30⁴ = 810,000행)이다.** 무작위 split의 holdout은
   "조합 보간"만 측정하고, 예측을 격자로 반올림하면 MAE가 인위적으로 좋아진다(누설).
3. **test 두께는 격자 밖 연속이다** — 라벨 없이 독립 두 방법(유계 노이즈 반증 / 디코더
   역해 격자거리 2.42 nm vs train 0.37)으로 확정했다. 즉 **holdout은 격자 위 보간,
   리더보드는 격자 밖 외삽**이고, 이 구분이 최종 판정을 뒤집게 된다 (§6).

## 3. 흐름 — 최종 방법에 도달한 결정 사슬

### 걸음 1. 신호 구조를 모델에 심는다 — 1D CNN (4.60 → 2.35 nm)

구조 bias 없는 대조군(MLP 512×3)이 4.599. 소박한 conv+GAP 이식은 오히려 **4배 나빴고**
(18.16), 채널 순서를 파괴한 셔플 대조군(12.23)보다도 나빴다 — "conv면 좋다"가 아니라
조건이 있다는 뜻이다. ablation으로 분해하면 ([level1_cnn.md](../reports/level1_cnn.md)):

- **수용영역이 전 대역을 덮어야 한다** (dilated, RF 97 → 259): 단독 +13.2 nm 개선 — 지배 요인.
  fringe 주기가 두께에 따라 크게 변하고 4층 beat가 겹치므로 국소 윈도우로는 두께의 결합
  정보를 인코딩할 수 없다.
- **파장축 위치가 보존돼야 한다** (GAP → flatten): 같은 무늬라도 어느 파장에 있는지가
  두께 정보다. dilated 위에서 시너지 → 2.93.
- **출력을 물리 범위 [10, 300] nm로 bound**: 범위 밖 예측(약 3.4%)이 만드는 격자 끝 오차를
  구조적으로 차단 → **2.346 (baseline −49%)**.

### 걸음 2. 물리 디코더를 데이터에 맞춘다 — TMM 캘리브레이션 (자유도 7)

물리를 쓰려면 먼저 미지수를 식별해야 한다 — 파장축은 비식별(채널 인덱스만 제공)이고
박막 물성도 미지다. 핵심 설계 원칙은 **물리 법칙을 자유도 개수로 강제한다**: 채널별 자유
곡선을 두면 재구성 오차는 내려가도 모델 오차가 물성으로 흡수돼 나온 곡선이 물성이 아니게
된다. 그래서 문헌 분산 법칙을 뼈대로 전체 자유 파라미터를 **7개**로 묶었다 — λ(c) 3계수
(두께축 주파수 식별의 닫힌형 초기값), SiO₂ Sellmeier **동결**(게이지 — δ = 2πnd/λ가
(n, λ) 공통 스케일에 축퇴라 하나는 고정해야 한다), SiN Sellmeier 2개, Si 실측표(Schinke
2015) + 2개. 판정은 사전 선언한 게이트 6종 ([stage_a.md](../reports/stage_a.md)):

- **통과**: 재구성 RMSE 0.009573 = **1.106σ**, 두께 역해 정확도 상한 **0.340 nm**, 채널
  홀드아웃 예측(매끈한 물리 분산만 가능한 검정, 한계 효과 +19.7%에서도 성립), λ 절대
  스케일 검정(1.00689), 물성값 전부 문헌 정합 + 독립 두 방법 0.32~0.74% 일치.
- **미통과 — 지우지 않았다**: 유계 노이즈 위반율 **9.99%** (완벽한 모델은 0%). forward
  모델은 불완전하다. 그래도 채택한 근거: 잔여 오차가 용도 대비 7배 여유(0.340 vs 규제
  대상 CNN 2.346)이고, 지배 성분의 상당 부분이 문헌표 간 불일치로 측정됐다. **수용한
  리스크**(물리가 0.34 nm 계통 편향 기준으로 예측을 당긴다)는 다음 걸음의 ablation이
  실제로 측정하게 된다.

### 걸음 3. 물리의 올바른 자리를 찾는다 — 손실 기각, 추론 채택 (2.35 → 0.61 nm)

physics-informed ML의 통념대로 캘리브레이션한 디코더를 **동결하고 학습 손실**에 걸었다:
L = MAE + β·L1(R_dec(d̂), R_obs). 사전등록(예측을 먼저 적고 검정) 후 β ∈ {0, 30, 100, 300}을
세 축에서 대조했고 — 무작위 split · held-out 두께 값 split(라벨이 모르는 두께를 디코더만
아는 상황) · 수렴 후 warm start — **전부 기각됐다**: val MAE가 β에 단조로 나빠지고, 적합
수준을 맞추면 이득이 0이다. 원인도 특정된다 — 관측이 R(d)+ε라 물리 항은 지도 항의 노이즈
낀 대리이고, 게이트 (b)를 못 넘은 디코더의 계통 편향으로 예측을 당긴다
([stage_b.md](../reports/stage_b.md) — U자 예측이 어긋난 기록까지 보존).

같은 동결 디코더를 **추론 후 보정**으로 옮기면 결과가 뒤집힌다
([inversion_refine.md](../reports/inversion_refine.md)): CNN 예측을 출발점으로 관측
스펙트럼에 배치 Levenberg–Marquardt 역산(해석적 야코비안 — 물리 테스트가 autograd 대조로
보증) → holdout **2.3455 → 0.6110 nm (−74%)**, 98%의 행이 개선. 결정적 대조군: 격자
중앙에서 출발한 같은 LM은 **77.68 nm로 실패**한다. 역할이 갈린다 —

> **신경망이 하는 일은 정밀도가 아니라 올바른 fringe 분지 선택이고, 물리가 하는 일은
> 그 분지 안의 정밀화다.** β 손실이 실패한 이유도 여기 있다: 손실 항은 CNN에게 이미
> 할 줄 아는 일을 시켰다.

여기에 **라벨 없는 되돌림 규칙**을 얹는다: 재구성 잔차가 중앙값 + 5·robust σ(k는 사전등록 —
MAE를 보며 고르면 평가셋 선택이다)를 넘는 행은 LM이 잘못된 분지 바닥까지 성실하게 내려간
행이므로 보정을 버리고 CNN 예측을 쓴다(지목 행에서 CNN 13.59 vs LM 48.22 nm). 학습 예산
100에폭과 합쳐 0.66M 백본으로 **0.3880 nm — 213M 단독(0.3955)을 처음 넘었고**, 리더보드
제출로 격자 밖 전이도 확인했다(test 0.38733, −0.2%)
([cnn_recipe.md](../reports/cnn_recipe.md)).

### 걸음 4. 남은 병목을 진단하고 푼다 — 잔차 + 깊이 ×2 + rFFT (백본 0.36 nm)

100에폭 CNN의 일반화 격차(val − train)가 0.243으로 **213M과 같았다** — 정규화·최적화
여지는 소진됐고 남은 차이는 순수 적합력이다(train 손실 1.4754가 순차 스택의 벽). 구조 →
용량 → 부착 모듈 순서로 풀었다 ([task8.md](../reports/task8.md)):

- **잔차 연결**이 같은 파라미터 수에서 벽을 뚫고(1.4754 → 1.4033), **깊이 ×2**(블록 10,
  1.51M)가 무너뜨린다(train_l1 0.3071, val 0.3647). 폭 ×2(2.62M)는 42% 많은 파라미터로
  val이 3배 뒤진다 — **작은 모델이 버는 방향은 폭이 아니라 깊이다** (213M은 폭으로 큰 모델).
- 부착 모듈은 물리 근거가 있는 둘만: **rFFT 입력 분기**(간섭무늬는 주기 신호, +0.5% 파라미터,
  val 0.3589)와 SE 채널 어텐션(EDA의 채널 정보량 3배 불균등 근거, val 0.2954 — CNN 단독
  최강). 결합은 동률(이득이 겹침).
- 판정은 val이 아니라 **post-LM MAE + 분지 실패율**로(pre-LM 정밀도 개선은 post-LM에 남지
  않는다), 표본이 아니라 전체 holdout 81,000행으로 한다. 이때 **물리 보정의 교차점**이
  관측됐다: LM의 한계 기여가 −74% → −6.4% → d2-se에서 **음수**로 붕괴 — CNN이 디코더의
  내재 정확도(상한 0.3336)를 넘는 순간 LM은 해를 계통오차 쪽으로 끌고 간다.

## 4. 최종 결과 — 3자 비교

채택 = `task8/d2-fft` + LM 역산 + 되돌림. 수치 정본:
[task8_judge.md](../reports/task8_judge.md) · [leaderboard.json](../reports/leaderboard.json) ·
[task8_bench.md](../reports/task8_bench.md).

| | 파라미터 | holdout MAE [nm] | test MAE [nm] (격자 밖) | 전이 |
|---|---|---|---|---|
| 213M skip-MLP 단독 (1위 재현) | 213.2M | 0.3955 | 0.4752 | +20% |
| d2-fft 단독 (raw CNN) | 1.52M | 0.3589 | 0.5911 | +65% |
| **d2-fft + LM + 되돌림 (채택)** | **1.52M + 물리 7** | **0.3396** | **0.33895 (4위)** | **−0.2%** |

| 자원 미터 | 채택 파이프라인 | 213M 단독 | 배수 |
|---|---|---|---|
| 파라미터 / 체크포인트 | 1.52M / 6.1 MB | 213.2M / 813.6 MB | **140배 / 133배 작다** |
| 학습 (100에폭, L4) | 약 54분 | 199분 | 3.7배 빠르다 |
| 추론 (CPU / L4, ms/행) | 0.999 / 0.070 | 0.705 / 0.047 | 1.4~1.5배 느리다* |
| 정확도 (holdout / test) | **0.3396 / 0.33895** | 0.3955 / 0.4752 | **−14% / −29%** |

해석적 야코비안 + 조기 종료로 중앙차분 대비 10~16배를 걷어낸 값이다. 추론 배수는 기계에
따라 승패가 뒤집히므로 기계 이름과 함께만 인용한다
([inversion_bench.md](../reports/inversion_bench.md)).

## 5. 핵심 발견 — 격자 밖 반전: 물리의 값어치는 강건성이다

![격자 밖 반전 slopegraph](../reports/figures/fig_offgrid.png)

holdout 최강은 d2-se raw(0.2954)였지만 test에서 0.5461로 **+85% 붕괴**했다. 측정한 raw
신경망 셋 전부 — 우리 두 모델과 213M 1위 재현까지 — 격자 밖에서 열화했고(+20~85%), **물리
파이프라인만 열화 없이 전이됐다**(−0.2%). 정확도가 좋아질수록 raw 신경망은 학습 격자의
구조를 흡수하고 그 이점은 연속 두께에서 사라진다 — §2의 사실 ②③이 0.2 nm 스케일에서
실증된 것이다.

붕괴는 제출 전에 **라벨 없이** 예측됐다: 재구성 잔차의 holdout↔test 꼬리 비교가 신호였고
열화와 단조다(꼬리 1.95배 → +65% · 2.3배 → +85%, `scripts/check_submission_transfer.py`).
단 관문의 검출 범위는 격자 끌림 붕괴까지다 — 213M은 꼬리 1.03배로 통과하고도 +20% 열화했다
(잔차는 노이즈 바닥 아래 sub-nm 보간 오차에 둔감). 그래서 규칙은 "관문 통과 시 제출"이
아니라 **raw 제출 자체를 하지 않는 것**이다. 같은 잔차는 행 단위 신뢰도 지표로도 작동한다
(실제 오차와 순위상관 ρ 0.70, 잔차 상위 10%의 MAE 4.97 vs 하위 0.60 nm — fab의 계측 이상
감지 관점, [cnn_recipe_axes.md](../reports/cnn_recipe_axes.md)).

물리 결합의 값어치는 프로젝트를 관통하며 두 번 재정의됐다: **손실이 아니라 추론에**(걸음 3),
추론에서도 **정밀도 회복이 아니라 분포 이동에 대한 강건성 + 라벨 없는 신뢰도에**(이 절).
최종 채택이 CNN 최강(d2-se)이 아니라 파이프라인 최강(d2-fft)인 이유다.

## 6. 평가 정직성 — 시뮬레이션 격자 데이터의 함정 통제

수치의 신뢰를 위해 스스로에게 건 규약들이고, 전부 실측으로 뒷받침된다:

- **격자 스냅 금지**: holdout MAE를 2.346 → 1.287로 만들지만 생성 방식의 누설이고,
  test(연속)에서는 약 +1.2 nm 순손실이다. 같은 계열인 범위 클리핑(holdout −0.0076)도
  기각 — holdout만 참 두께의 6.71%가 격자 끝에 쌓여 생기는 인공물이다.
- **사전등록**: 실험마다 예측을 먼저 적고 검정했다. 빗나간 예측(β U자, 213M 관문 통과 후
  무열화)도 기록으로 보존 — 어긋난 기록이 판정의 재현성을 만든다.
- **Δ는 대조군 기준, 순위는 표본 잡음과 함께**: 사슬 실험의 Δ를 직전 부모 대비로 읽지
  않고, post-LM 순위는 5,000행 표본 1σ(±0.037 nm) 아래를 동률로 처리, 확정은 전체
  holdout(표본 오차 0)으로만.
- **모든 수치는 스크립트 산출물에서만 인용** — 손계산 수치가 정본과 어긋난 사례가 실제로
  두 번 잡혀 규약이 됐고, 리더보드 실측조차 기계가독 정본(leaderboard.json)으로 관리한다.

## 7. 한계

- **물리 디코더의 계통오차가 남은 바닥이다** (게이트 (b) 9.99% 미통과 → post-LM 하한
  ≈ 0.334 nm). 잔차가 몰리는 곳은 문헌 분산식 유효범위 밖의 단파장 끝 — 물성 모델 형태의
  개선이 유일한 남은 레버이고 마감 내 범위 밖으로 기록했다.
- **등가 분지 실패는 잔존한다**(채택 모델 0.07%). 되돌림 규칙이 줄이는 것은 건수가 아니라
  심각도이고, 남는 실패는 관측을 거의 같게 설명해 잔차로 구분되지 않는다.
- 수직입사·등방성·평행 평면층·거칠기 없음 가정. 되돌림 문턱은 transductive(행 집합의 잔차
  분포에서 생성)라 단행 배포에는 사전 계산 문턱이 필요하다.
- 모듈 vs 깊이 연장(d4)의 직접 비교는 미측정으로 남았다.
