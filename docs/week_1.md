## 2026-08-12 (수) — Task 6 완료: Stage A 파라미터화 재설계 + 게이트 개정

전날 파라미터화의 구조적 문제를 지적받았다 — "TMM에 필요한 채널 파장 / SiN n / Si n·k를
전부 독립적으로 경사하강에 맡겼는데, 뒤 둘은 물리적으로 파장의 함수다. 그러면 가산
노이즈 기준 전체 게이트는 통과해도 각각의 값은 물리적으로 무의미할 수 있다."
**맞았고 이미 일어난 일이었다** (k_Si 톱니). 취합: [reports/stage_a.md](../reports/stage_a.md).

### 착수 전 평가에서 확인한 사실

- **게이지-불변 검정이 이미 가능했다**: 주파수 식별의 f_SiN/f_SiO₂ = n_SiN/n_SiO₂ 는
  λ 할당과 무관한 관측량이다. 문헌 대비 **−2.15% 균일 편차, 분산 모양은 96% 일치**.
  λ 스케일 오차로 설명하려면 λ를 41% 틀려야 하므로 **λ축은 맞고 SiN 박막의 n이 2%
  낮다**(조성 차이). → **SiN을 문헌값에 동결하면 안 된다** (측정된 2%를 주입하는 셈).
- **Cauchy 절단 근사는 잔차의 원인이 아니다**: 정확 Sellmeier 대비 SiO₂ 4.05e-4 /
  SiN 1.03e-3 (n), d=300 nm에서 위상 ≤ 0.0008 주기. 후보에서 기각.
- **채널별 λ를 그대로 고정하면 안 된다**: 0.445 nm rms 흔들림이 있고(다항 차수를
  1→6으로 올려도 안 줄어드니 추정 잡음), 그것만으로 R 오차 rms 0.0047 — 없애려는
  계통오차 0.0034보다 크다. → **3계수 매끈 곡선**으로 고정하는 것이 정답.
- **σ를 확정했다**: 채널축 m차 차분이 m=5~8에서 **0.008658**로 6자리 고정
  (`scripts/measure_noise.py`). 이전 0.0087~0.0088은 2차 차분 상한이었다.
  두께축으로는 같은 추정이 불가능함도 확인 (주기 1.07~4.5개로 과소표집).
- **노이즈가 유계임을 확정했다**: 1.83억 관측 중 R < −0.0152가 **0건**, σ√3 = 0.014996.
  → **새 게이트 (b)**: 잔차가 0.0152를 넘는 관측은 통계 없이 모델 오류의 증거.
  전날 모델을 이 잣대로 재보니 **8.5%가 위반** — 기존 게이트가 약했다.

| + SiN C₁, Si ΔE·k | 7 | **0.009941 (1.148σ) ✓(a)** | 12.01% | **0.388** |

- **Si 실측표 + 에너지축 스플라인이 단일 최대 기여** — 같은 자유도 1개로 역해 MAE
  1.104 → 0.663 nm. 거친 19점 표는 E1 봉우리를 6.767 → 6.479로 깎는다. 전날 "문헌보다
  뾰족한 임계점을 복원했다"고 본 것은 **선형 보간으로 깎인 봉우리를 피팅이 되메운 것**.
- **채널 홀드아웃 통과**: 20채널을 피팅에서 빼고 예측 → RMSE 0.010229 vs 피팅 채널
  0.009914 (**1.032배**). 채널별 자유 파라미터를 쓰는 모델은 원리적으로 불가능한 검정.
  (**08-13 리뷰 보완**: 이 비에는 대조군이 빠져 있다 — 전 채널 적합 모델도 같은 20채널에서
  1.029가 나오므로 홀드아웃의 한계 효과는 +0.3%다. 본 증거는 단파장 끝 연속블록 판본.)
- **파라미터가 독립 두 방법과 일치**: SiN B₁ 2.8564(주파수) vs 2.8735(TMM) = 0.60%,
  √C₁ 131.26 vs 131.66 nm = 0.30%. λ는 채널별 추정 산포(0.445)보다 적게 움직였다
  (0.368 nm rms) — **단 0.445를 오차 막대로 쓴 것은 08-13 리뷰에서 정정됐다**(아래).
  물성 전부 문헌 범위 내 (SiN −5%, Si ΔE −18.7 meV = 임계점 +18.7 meV 청색편이, k ×0.977).
- **상관행렬이 게이지 축을 보여준다**: ν₀ ↔ SiN B₁ = −0.687. B₁ ↔ C₁ = −0.915라 기본은
  B₁ 하나. Si는 λ·SiN과 거의 무상관(|ρ|<0.14 — 위상이 아니라 진폭 정보원).
- **속도**: 자유도가 줄어 LM 피팅이 11~63초 (전날 Adam 피팅은 phase 1+2에 ~1.6시간).

### 미해결 — 게이트 (b)를 통과하는 모델이 없다

최선이 12.0% 위반. 남은 오차는 **c-Si 임계점 E1(3.40 eV)·E2(4.25 eV)에 집중**
(±0.12 eV 38채널 18.7% vs 나머지 188채널 10.7%). 두께축으로는 구조 없음(11.2~13.3%,
평균 12.0% — 채널축의 8.4~39.4%에 비해 훨씬 평평하다).
원인 후보: ① Aspnes 표의 0.1 eV 해상도가 E1 폭과 비슷해 어떤 보간도 봉우리를 복원 못
함 → 임계점 파라메트릭 모형(Herzinger 1998 PSEMI), ② λ<310 nm **30채널이 Luke
Sellmeier 유효범위 밖 외삽**, ③ 층 k=0 가정(a-SiN:H UV 흡수 — Tauc-Lorentz의 자리),
④ 생성기가 순수 TMM이 아닐 가능성.

**Stage B 디코더 = `runs/stage_a/joint-lam3-sin2-si2/model.pt`** — 역해 MAE 0.388 nm이고
규제 대상 CNN이 2.346 nm이므로 물리 손실의 규제자로 충분하다.
