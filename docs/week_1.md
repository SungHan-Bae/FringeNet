- **상한 기준선 확보 — 1등 단일 모델 원본 재현 성공, holdout MAE 0.3955 nm**
  (보고치 ≈0.42와 같은 수준). 축소 재현이 아니라 원본 재현을 고른 이유: 축소판은 격차가
  스케일 탓인지 구현 실수 탓인지 구분하지 못한다. **0.66M(2.346) vs 213M(0.3955) 격차가

- **인프라 — 세션 유실 대비 4계약**(즉시 best 저장 / 에폭 단위 resume+RNG / Drive 미러 /

- **Stage A 착수에서 얻은 것 — 최종 설계에 그대로 남았다.** λ축 fringe 정렬을 경사하강에
  맡기면 잘못된 fringe 차수 분지에 안착한다(후보 16개 전부 RMSE ~0.12에서 정체).
  해법: 전수 격자의 조건부 평균이 두께축에서 f = 2n/λ로 진동한다는 성질로 λ를

## 08-12 (수) — Task 6: Stage A 파라미터화 확정 + 게이트 개정

**설계의 분기점은 파라미터화였다.** 채널 파장 / SiN n / Si n·k 를 전부 독립 자유도로 두면
(채널별 자유 곡선 ~900개) 재구성 RMSE는 노이즈 바닥까지 내려가지만, 뒤 둘이 물리적으로
λ의 함수라는 제약이 사라진다 — 손잡이가 모델 오차를 흡수해 전체 게이트는 통과해도 나온
값은 물성이 아니다(k_Si가 λ에 대해 톱니로 진동하는 식). 그래서 **자유도를 1~7개로 묶고**,
게이트도 잔차만 보지 않도록 개정했다.

- **σ 확정: 0.008658** (채널축 m차 차분이 m=5~8에서 6자리 고정). 평평해진다는 것 자체가
  잔차가 채널축에서 백색이라는 근거다. 두께축으로는 같은 추정이 불가능(과소표집).
- **🔴 노이즈가 유계임을 확정: |ε| ≤ 0.0152.** 1.83억 관측 중 R < −0.0152가 0건이고
  σ√3 = 0.014996이다(가우시안이면 5σ = −0.043까지 나와야 한다). → **새 게이트 (b)**:
  잔차가 이를 넘는 관측 하나하나가 **통계 없이** 모델 오류의 증거다. 이 잣대로 재보니
  채널별 자유 곡선 판본은 8.5% 위반 — 잔차 RMSE만 보는 게이트로는 보이지 않던 오차다.
- **게이트를 (a)~(f) 6종으로 개정.** 잔차만 보는 게이트는 계통오차를 파라미터로 흡수하는
  모델을 항상 유리하게 만들므로, **홀드아웃 예측력(e)** 과 **파라미터 물리성(f)** 을
  함께 본다 — (e)는 채널별 자유 모델이 원리적으로 통과할 수 없는 검정이다.
- 착수 전 확인: SiN을 문헌값에 동결하면 안 된다(게이지-불변 관측량이 −2.15% 편차) ·
  Cauchy 절단 근사는 잔차의 원인이 아니다 · 채널별 λ를 그대로 고정하면 안 된다.
- 두께축 주파수 식별을 `src/physics/freq_id.py`로 분리해 **run 하나가 자기완결적**이
  되게 했다 (외부 산출물을 참조하면 재현이 깨진다).

## 08-13 (목) — Stage A 종결 + 전수 리뷰

**Task 6 종결: 자유 파라미터 7개 + Si 표 Schinke 2015.** RMSE 0.009573 (1.106σ)로
게이트 (a) 통과, 두께 역해 MAE 0.340 nm, 채널 홀드아웃·λ 절대 스케일 검정 통과,
물성 전부 문헌 정합. **게이트 (b)는 미통과(9.99%)** — 채택 근거와 수용 리스크는
README §3.2에 명시. 취합: [reports/stage_a.md](../reports/stage_a.md).

- **Si 실측표 + 에너지축 스플라인이 단일 최대 기여**: 같은 자유도 1개로 역해 MAE
  1.104 → 0.663 nm. 거친 19점 표는 E1 봉우리를 4.3% 깎는다 — 거친 표 위에서 "문헌보다
  뾰족한 임계점을 복원했다"고 읽으면 안 된다(선형 보간으로 깎인 봉우리를 피팅이 되메운
  것이다).
- **🔴 Si 표 선택 근거를 기하학에서 측정으로 교체.** "Aspnes만 0.1 eV 균등 격자라 E1에
  격자점이 놓인다"는 논거가 반증됐다 — 에너지축 스플라인이 10 nm λ 격자에서도 봉우리를
  복원해 세 표의 E1 위치가 3.5 meV 이내로 일치한다. `si_source`만 바꿔 셋을 전부 적합하니
  네 지표가 같은 순서로 정렬 → **Schinke 채택**(위반율 −17%, 역해 MAE −12%).
- **🔴 test.csv의 두께는 10 nm 격자 위에 없다 — 연속이다.** 라벨이 없어 관측 불가라
  train과 같다고 암묵 가정해 왔는데, 유계 노이즈 반증과 디코더 역해가 독립적으로 일치한다.
  → 격자 스냅은 **train/holdout에서만 누설**이고 test(제출)에서는 MAE를 약 +1.2 nm
  악화시킨다. 그리고 "합성해야 한다"던 격자 밖 일반화 평가셋이 **이미 test로 존재한다**.
- **λ 절대 스케일 검정 통과** (s = 1.00689): 위상 정보만으로는 (n, λ) 공통 스케일이
  축퇴라 원리적으로 검증 불가한데, Si를 에너지축에 동결해 임계점을 절대 앵커로 쓰면
  Fresnel **진폭**이 축퇴를 깬다.
- **게이트 (e)가 판별력을 갖게 됐다**: 균등 간격 20채널은 한계 효과 +0.3%로 사실상
  보간이었다. 단파장 끝 **연속 블록**에서 +19.7%이고 그래도 예측이 성립한다.
- **🔴 게이트 (b) 후속 우선순위를 측정으로 재배열.** 채택 모델의 최악 채널은 E1이 아니라
  대역 단파장 끝(ch222–225)이고, **그 구간에는 문헌표 불일치가 거의 없다**(0.38σ, 기준보다
  작다) — 표로 설명되지 않는 모델 부족이다. 반면 E1 구역은 위반율과 표 불일치가 함께
  크다. → ① SiN 단파장 분산 + 층 k=0 ② 임계점 파라메트릭 모형 ③ 계면층 순.
- 겪은 함정: 백그라운드 run이 도는 중에 `src/`를 편집해 `PARAM_NAMES`는 새 것,
  `inits`는 옛 것인 순간에 걸려 크래시. **run 중에는 `src/`를 건드리지 않는다.**

### Task 7 착수 — 물리 손실 배선 (같은 날)

손실을 `src/losses.py`로 분리하고 GPU 경로에 배선했다. **CLAUDE.md의 계약 충돌을 먼저
정리**했다 — 「모델·학습 스펙」은 `src/train.py --physics`였는데 「코딩 규약」은 그 파일을
수정 금지(CPU baseline 재현 경로)로 못 박고 있다. Task 7은 GPU가 필요하므로 손실을 별
모듈로 두고 `train_gpu.py`가 `train.physics` 블록으로 켠다 (로컬 CPU에서 단위 테스트 가능).

- **동결을 두 겹으로 강제**: `theta.requires_grad_(False)` + 디코더가 파라미터를 아예
  보유하지 않는다(상수 분광량만 버퍼). theta가 동결이면 (λ, n, n_s)가 상수이므로 1회
  계산해 complex64로 캐스팅·캐시한다 — 매 스텝 Sellmeier·스플라인을 다시 돌지 않고,
  소비자 GPU의 float64 처리율(1/32)도 피한다. 캐스팅 오차 max **6.0e-6** (σ의 0.07%).
- **beta=0 대조군의 학습 경로가 물리 항 도입 전과 비트 동일하다**: 물리 항을 그래프에
  넣지 않고 진단으로만 기록한다. 단위 테스트(gradient 비트 비교)와 실데이터 스모크
  (holdout MAE 45.5536804199 — 물리 블록 없는 run과 10자리 일치)로 고정했다. 이게 없으면
  ablation의 차이가 물리 항 때문인지 코드 경로 차이 때문인지 구분할 수 없다.
- **순환 import을 만나 의존 방향을 고쳤다**: `calibrate`(Stage A, CPU)가 `train_gpu`에서
  `_atomic_save`를 가져오고 있었다 — `train_gpu → losses → calibrate`가 붙자 순환이 됐다.
  헬퍼를 `src/utils/io.py`로 올렸다 (역방향 의존 자체가 원인이었다).
- 사전등록 항목 4(누수)를 테스트로 고정: 전수 조합이라 두께 4개가 행의 유일 키가 되므로
  캘리브레이션 표집 70,000행 ∩ holdout 81,000행 = 0을 **표본이 아니라 전수로** 확인한다.
- config 4종 `configs/stage_b/beta{0,30,100,300}.yaml` — 백본은 Level 1 확정
  flatten-dilated-bound 그대로, 조작 변인은 `physics.beta` 하나. 물리 항 워밍업 3,000스텝
  (≈2.1 에폭, LR 워밍업 1,000과 별개). 스케일 감각: 참 두께에서 재구성 L1의 하한은
  E|ε| = **0.0075**이고 학습 초기에는 0.21 수준이라 beta 100이 두 항을 같은 자리수로 맞춘다.
- CPU 스모크(2만 행 × 2에폭) 오버헤드: 진단만(beta=0) 1.07배, beta>0도 +2% 수준.
  GPU 오버헤드는 라운드에서 측정한다 (커널 런치가 지배적일 수 있다).

### 평가 축 2종 구현 (같은 날)

**random split 하나만 보면 β ablation이 "차이 없음"으로 끝날 위험이 크다** — 전수 격자라
조합 보간이 이미 쉽다. 그래서 판정 도구를 먼저 만들었다. README §3.5의 4종 중 **3종 구현**
(②는 test에 라벨이 없어 리더보드 제출로만 가능).

- **`scripts/evaluate_axes.py`** — 학습 없이 체크포인트 위에서 도는 두 축. 주입 노이즈는
  수준마다 실현을 고정해 모든 run이 **같은 입력**을 본다(차이를 난수가 아니라 모델에
  귀속). 시작 시 기록된 holdout MAE를 재추론으로 대조해 손상된 체크포인트를 걸러낸다.
- **확정 백본에서 이미 나온 수치** (level1_cnn/flatten-dilated-bound, holdout 8,000행):
  균등 ±0.015 주입에 MAE 2.353 → **2.690**, ±0.030에 3.867. **균등과 가우시안이 총 σ만
  같으면 거의 같은 열화**를 준다(2.6895 vs 2.6999) — 분포 모양이 아니라 σ가 성능을 정한다.
- **신뢰도 지표가 실제로 작동한다**: 라벨을 쓰지 않는 행별 물리 잔차와 실제 오차의
  Spearman **0.689**, 잔차 최고 십분위의 MAE **6.618** vs 최저 십분위 **0.885**(7.5배),
  상위 10% 포착률 **56.8%**(무작위면 10%). 잔차 중앙값 0.0253은 바닥(참 두께에서 0.0080)의
  3배라 지표가 노이즈 바닥에 눌려 있지 않다. **β와 무관하게 성립하는 Stage B의 부산물**이다.
- **held-out 두께 값 split**(`data.holdout_thickness`) — 70·150·230 nm를 전 층에서 빼면
  학습이 27⁴ = 531,441행으로 정확히 떨어진다(테스트로 고정). 한 층에서만 빼면 그 값이 다른
  층을 통해 학습에 남아 "보지 못한 값"이 아니게 되므로 전 층에서 뺀다.
- 분할 옵션이 늘어 **`prepare_from_config`로 학습·평가·진단의 분할 재현을 한 함수로 모았다**
  (한쪽만 갱신되는 드리프트 차단). resume 지문에도 `data` 블록을 넣었다 — 값만 바꾼 split은
  학습 집합 크기가 같아 `n_train`만으로는 안 걸린다.
