# 실험 리포트: stage_b — Task 7 물리 손실 β ablation + 물리 역산

2026-08-11. 브랜치 `task7-stage-b`, 학습 Colab T4 (`notebooks/stage_b/round1_beta-ablation.ipynb`),
분석 `scripts/diagnose_stage_b.py` (수치·그림 전부 스크립트 산출 — `reports/stage_b_metrics.md`).

**한 줄 결론: 물리(TMM)는 크게 기여하지만, 자리가 손실 항이 아니라 추론이다.**
학습 손실에 넣은 물리 항(β>0)은 β에 단조로 성능을 해친다(+3%~+54%).
반면 같은 동결 디코더로 예측을 역산 refinement하면 **2.346 → 0.4877 nm (−79%)**,
322배 큰 213M 상한 기준선(0.3955 nm)과의 격차를 1.95 nm에서 0.09 nm로 좁힌다.
물리 잔차는 라벨 없는 신뢰도 지표로도 유효하다(Spearman ρ 0.69).

## 설정 (변인 통제)

- 백본: Level 1 확정 flatten-dilated-bound 1D CNN 0.66M ([level1_cnn.md](level1_cnn.md)),
  시드 42·30 epochs·프로토콜 전부 동일 — **조작 변인은 β 하나**.
- 손실: `L = MAE(d̂, d) + β·L1(R_dec(d̂), R_obs)`, β는 3,000스텝(~2.1에폭) 선형 워밍업.
  디코더 R_dec = Stage A 게이트 통과 동결 TMM (`runs/stage_a/sio2-freeze-refine`,
  재구성 RMSE 0.00929 = 1.07σ, [stage_a.md](stage_a.md)) — 학습 파라미터 없음, grad는 d̂로만.
- β ∈ {0, 30, 100, 300}: d-MAE ~2 nm vs 물리 잔차 ~0.01 스케일에서 β≈200이 두 항 균형
  (`configs/stage_b/beta100.yaml` 헤더). beta0 = 물리 off 대조군.

### 물리 역산 — 디코더 단독 최적화가 보여주는 것

행별로 d를 L1(R_dec(d), R_obs)에 Adam 최적화 (라벨 미사용, 연속값 —
격자 정보를 쓰지 않으므로 격자 스냅 누설과 무관):

| 대상 | 행 수 | init → 역산 후 MAE [nm] | 층별 (L1/L2/L3/L4) |
|---|---|---|---|
| (a) 참값 초기화 = **물리 손실의 최적해** | 2,048 | 0 → **0.3592** | 0.280 / 0.489 / 0.328 / 0.340 |
| (b) beta0 예측 초기화 = **추론 후처리** | 81,000 (전체) | 2.3455 → **0.4877** | 0.395 / 0.616 / 0.445 / 0.495 |

- (b) 행별 분포: **median 0.281 nm**, P90 0.691 nm, 98.1% 행이 개선, 5 nm 초과 잔류
  0.77% (잘못된 fringe 분지 의심 — 평균 0.488과 중앙값 0.281의 간극은 이 꼬리가 만든다.
  분포는 `figures/fig_stage_b_inversion.png`).
- (a)의 0.359 nm는 이 디코더+노이즈 조합에서 물리 정합으로 도달 가능한 경험적 바닥이다.
  역산 후 잔차 0.00774는 참값 잔차 바닥 0.00788을 근소 하회 — 노이즈 일부를 d로
  흡수하는 예상된 규모이며, 그 대가가 참값에서 0.36 nm 벗어남이다.

쓰지 않아 test 추론에 그대로 적용 가능하다.*

## 분석

### 1. 왜 학습 손실로는 해가 되나 — "타깃 편향" 가설은 기각

가장 그럴듯한 가설은 "물리 항이 노이즈 낀 R_obs에 맞추도록 d̂를 참값 밖으로 당긴다
(타깃 편향)"이지만, 역산 실험 (a)가 이를 기각한다: 물리 손실만의 최적해는 참값에서
겨우 0.359 nm 떨어져 있다 — β→∞가 당기는 타깃은 현재 모델의 오차(2.3 nm)보다 6배
좋은 곳이다. 열화는 목적지가 아니라 **가는 길**의 문제다:

- **정보를 더하지 않는다**: 모든 학습 행에 정확한 라벨 d가 있으므로, R_obs = R(d)+ε는
  d에 조건부로 노이즈뿐이다. 물리 항은 지도 항의 노이즈 낀·재가중된 대리 손실이고,
  전수 라벨 하에서 최선의 경우가 "중립"이다.
- **민감도 재가중이 역효과**: 물리 항의 d̂ gradient는 국소 민감도 ∂R/∂d에 비례한다.
  스펙트럼이 평평한 얇은 두께(10~30 nm)와 layer_2(최저 SNR 10.3)는 민감도가 낮아
  gradient가 약해진다 — 정확히 오차가 가장 큰 곳의 학습이 억눌린다. 실제로 beta300
  열화는 얇은 구간에 집중된다 (`figures/fig_stage_b_thickness_bins.png`: 전 층에서
  10~30 nm 구간이 최다 열화, layer_2가 전 구간에서 최악).
- **노이즈 바닥의 gradient 오염**: d 오차가 σ/민감도 ≈ 1 nm 수준에 접근하면 물리 항
  gradient는 ε 맞추기가 지배한다. SGD+제한된 용량의 학습에는 유해하지만, 행별 역산은
  226채널 평균으로 이를 흡수한다(그래서 (a)가 0.36 nm까지 감).

### 2. 물리의 올바른 자리 — 추론 시 역산 refinement

CNN이 올바른 fringe 분지(±2.3 nm ≪ fringe 주기 ~100 nm대)까지 데려다 놓으면,
그 안에서의 정밀 위치는 물리 정합이 신경망보다 잘 푼다 — 분광 계측의 고전적
model-based fitting과 같은 구조다. 역할 분담: **CNN = 전역 분지 선택(amortized init),
TMM = 분지 내 정밀 피팅**. 이 조합(0.66M + 물리)이 213M 순수 신경망과의 격차
1.9500 nm 중 1.8578 nm(**95.3%**)를 회수한다. 잔여 0.09 nm 격차의 상당 부분은
0.77% 오분지 꼬리다 — 전형 행의 오차는 중앙값 0.281 nm 수준이고 평균(0.4877)은
꼬리가 끌어올린다 (중앙값·평균은 통계량이 달라 타 모델 MAE와의 직접 비교는 평균으로만).

### 3. 신뢰도 지표 — 물리 잔차로 라벨 없이 오차를 선별

행별 물리 잔차 r = mean|R_dec(d̂)−R_obs| ↔ 행별 실제 오차의 상관 (beta0 기준
Pearson 0.700 / Spearman 0.691, 전 run 0.69~0.74):

| 잔차 십분위 | D1 | D5 | D9 | D10 |
|---|---|---|---|---|
| mean 오차 [nm] | 0.861 | 1.740 | 3.408 | **6.540** |

잔차 상위 10%를 걸러내면 평균 오차의 최악 집단(전체 평균의 2.8배)을 라벨 없이
표적할 수 있다 — test 추론에서 재측정·수동 확인 대상 선정에 쓸 수 있는 실용 지표.
십분위 캘리브레이션은 `figures/fig_stage_b_confidence.png`.

### 4. 부수 확인 — layer_4 민감도 저하 구간 (백로그 열린 항목)

EDA가 예고한 layer_4 40~60 nm 민감도 국소 최소에서 beta0 MAE 2.664 vs 그 외 2.034
(1.31×) — 사각 구간이 오차로 실재함을 확인. 관측 한계(EDA: 최소 SNR 10.3으로 원리적
사각지대 없음)가 아니라 상대적 난이도로, 역산 refinement 후에도 layer_4는 L2 다음으로
오차가 크다(0.495).

## 결론

1. **β ablation (Task 7 목표)**: 전수 라벨 조건에서 물리 손실은 β에 단조로 유해
   (+3.4%@β30 ~ +54%@β300). 원인은 타깃 편향이 아니라(역산이 기각) 정보 무추가 +
   민감도 재가중 + 노이즈 바닥의 최적화 간섭.
2. **물리의 기여는 추론에서 실현**: 동결 TMM 역산 refinement로 0.66M CNN이
   **0.4877 nm** — 물리 디코더 채택(Stage A)의 가치가 여기서 정량화된다.
   같은 물리 자산이 손실로는 −, 추론기로는 −79%.
3. **신뢰도 지표 (Task 7 목표)**: 물리 잔차는 라벨 없는 오차 예측자 (ρ≈0.69,
   D10/D1 = 7.6×).

## 한계·미탐색

- β 학습 변형 미탐색: 잔차의 노이즈 바닥 클리핑(soft-L1/Huber δ≈σ), 민감도 역가중,
  물리 항 후반 투입 등은 열화를 없앨 수 있으나, 역산 결과가 상한(0.36 nm)을 이미
  보여주므로 우선순위 낮음. 채널 가중 ablation(백로그)도 같은 이유로 보류.
- 물리 손실의 정당한 무대는 **라벨 희소** 시나리오(반지도: test R_obs에 물리 항)다 —
  본 데이터(전수 라벨)에서는 검증 불가, 한계로 기록.
- 역산 refinement의 0.77% 오분지 꼬리: 다중 초기화·신뢰도 지표 결합(잔차 큰 행만
  재시도)으로 줄일 여지. holdout은 10 nm 격자 두께 분포라 비격자 일반화는 split 3종
  평가(격자 밖 합성셋)에서 별도 확인 대상.
- 역산은 행당 Adam 400 step (holdout 81k 전체 CPU ~10분) — 추론 비용은 CNN 단독보다
  크지만 213M 모델 추론·학습 대비로는 가볍다.
