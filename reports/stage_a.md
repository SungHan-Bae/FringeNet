# 실험 리포트: stage_a — Task 6 Stage A 캘리브레이션 (TMM forward 미지수 피팅)

2026-08-11. 대실험 주제: **비식별 파장축·미지 분산을 train (d_true, R_obs)에서 역추정**해
TMM을 Stage B의 물리 디코더로 쓸 수 있는지 게이트로 판정한다.
산출물: `runs/stage_a/<변형>/` (model.pt, train.log, metrics.json),
게이트 수치는 [stage_a_gate.md](stage_a_gate.md) (`scripts/diagnose_calibration.py` 산출).

**판정: 게이트 통과 — TMM을 물리 디코더로 채택한다.** 재구성 RMSE **0.00929**
(기준 0.0105 = 1.2σ, 노이즈 바닥 σ = 0.0087의 **1.07배**), 잔차는 두께·채널에 대해
구조 없이 평평하고 분포가 데이터 노이즈(균등에 가까움)와 일치한다. 잔여 비백색
성분은 lag-1 자기상관 +0.127로 정량화되는 매끈한 모델 오차 ~0.0033 (σ의 38%)이
전부다 — 아래 "판정 상세" 참조.

## 설정 (무엇을 학습하고 무엇을 고정하나)

- 구조: 공기 / SiN / SiO₂ / SiN / SiO₂ / Si 기판, 수직입사 (CLAUDE.md 도메인 계약).
- **게이지 고정**: delta = 2πnd/λ 가 (n, λ) 공통 스케일에 불변이라 둘을 동시에 자유
  학습하면 물리적으로 무의미한 해에 안착한다. **SiO₂ n(λ)를 Malitson 1965 Sellmeier의
  Cauchy 근사에 freeze**하고 λ 그리드와 나머지 재료만 학습했다.
- 학습 대상: λ 그리드(단조 파라미터화 `lam_min + cumsum(softplus)`, 방향 자유),
  SiN n(λ) (k=0 가정), Si 기판 n(λ)·k(λ) (k ≥ 0, softplus).
- dtype complex128. 표본: fit 50,000 + 진단 20,000행 — **프로젝트 공통 holdout을 뺀
  train에서 표집** (Stage B 평가와의 정보 누설 차단). 게이트 수치는 전부 피팅에 쓰지
  않은 진단 표본 기준.

## 방법 — 3-phase 파이프라인 (`src/calibrate.py`)

**Phase 0 — 두께축 주파수 식별 (닫힌형, 결정론).** λ축 fringe 정렬은 경사하강에
비볼록이라 초기값이 틀리면 잘못된 fringe 차수 분지에 안착한다(아래 반복 이력의
후보 탐색 실패). 대신 타깃이 30⁴ 전수 격자인 점을 써서, 층 j로 조건화한 평균
`g_c(d) = E[R_c | d_j = d]`(30점)를 만들면 이 곡선은 두께축에서 기본 주파수
**f_j(c) = 2·n_j(λ_c)/λ_c** 로 진동한다 (특성행렬 M_j가 δ→δ+π에서 부호만 바뀌어
R은 δ_j에 π 주기). SiO₂(층 2·4)는 게이지로 n(λ)를 아니까 f₂·f₄에서 **λ_c가
채널별로 바로 풀리고**, SiN은 n(λ_c) = f₁·λ_c/2 추정을 준다. 자체 검증 3중:

| 검증 | 결과 |
|---|---|
| 층 2 vs 층 4의 독립 λ 추정 일치 | 편차 중앙값 **0.00 nm** (226채널 중 8채널만 >5 nm — 이웃 보간 처리) |
| 층 1 vs 층 3의 n_SiN 추정 일치 | 곡선 일치 (동일 재료 확인) |
| n_SiN vs 문헌 (Luke 2015) | 중앙 상대편차 **2.2%** |

식별 결과: **λ = 284–793 nm, 채널 내림차순** (채널 0 = 장파장) — EDA의 "대역 오른쪽
끝 신호 3배" 관찰과 정합(짧은 λ일수록 두께 민감도가 큼). 조건부 평균은 정확한
주변화가 필요해 이 단계만 holdout 제외 train 전체(~73만 행, bin당 ~2.4만 행)를 쓴다
(5만 행 표본은 bin 노이즈로 추정이 흔들림 — 합성 실험으로 확인, 테스트 고정).

**Phase 1 — 매끈한 물리 피팅** (`sio2-freeze`): 식별된 그리드에서 λ(단조)·SiN
Cauchy(3계수)·Si knot 24점을 Adam으로 공동 피팅. 진단 RMSE **0.01254**.

**Phase 2 — 채널별 공동 미세조정** (`sio2-freeze-refine`): phase 1이 0.0125에서
정체하는데, 채널별 자유 TMM(채널마다 λ·n_SiN·n_Si·k_Si)은 전 채널 RMSE
0.0093~0.0099로 노이즈 바닥까지 내려간다 — **TMM 모델족은 충분하고 매끈함
파라미터화의 경직성이 병목**. 단일 자유도 절제(Δλ만/n_SiN만/Si만 채널별 해방)는
각각 −0.0004 이하로 효과가 없어 **결합 보정**이 필요함도 확인. 이에 게이지(SiO₂
freeze)와 λ 단조 파라미터화는 유지한 채 SiN·Si 곡선만 채널별(knot=226)로 풀고
phase 1 결과에서 워밍스타트(`init_from_run`). 진단 RMSE **0.00929**.

## 판정 상세 ([stage_a_gate.md](stage_a_gate.md), 그림 2종)

- **(a) 재구성 RMSE**: 0.00929 < 0.0105 — **통과**. RMSE/σ = 1.068.
- **(c) 잔차 백색성** — 수치 진단 6종 중 5종 통과:
  - bias +0.00014 (≈0) ✓ / 채널 RMSE max/min 1.084 ✓ (평평) /
    두께 bin RMS max/min ≤ 1.025 전 층 ✓ (두께 의존 구조 없음 — (c)의 핵심 기준) /
    RMSE/σ_hf 1.071 ✓ / 잔차 분포가 균등형 노이즈와 일치 ✓ (fig_stage_a2 좌하)
  - **lag-1 자기상관 +0.127 (참고 기준 0.1 초과)** — 유일한 잔여 신호. 고주파 잔차
    크기 σ_hf = 0.00868이 데이터 노이즈 σ = 0.0087과 일치하므로, 이 자기상관은
    RMS ~0.0033(= √(0.00929²−0.00868²), σ의 38%)짜리 매끈한 모델 오차의 서명이다.
    두께·채널 구조가 평평하고 크기가 σ와 일치한다는 (c)의 정의는 충족 — 잔여분을
    한계로 명시하고 채택한다.
- **분산 곡선 육안 확인** (fig_stage_a1, CLAUDE.md 필수 절차):
  - λ 그리드: 284–793 nm 내림차순, 매끈 (반복 1의 꺾임 소멸). 1/λ에 가까운 간격.
  - n_SiN 1.99–2.16: Luke 2015보다 일관되게 ~0.03–0.05 낮은 매끈한 곡선 — SiN 박막
    굴절률은 조성에 따라 1.9~2.3 범위라 물리적으로 타당.
  - n_Si: **E1 임계점(~370 nm) 피크까지 문헌(Aspnes & Studna 1983)을 추종** — 문헌
    테이블(선형 보간)보다 오히려 뾰족한 실제 임계점 모양을 복원했다.
  - k_Si: ~450 nm까지 문헌 추종. 그 위(가시광 장파장)에서는 0.03~0.1 사이에서 진동 —
    **약식별 구간** (k가 작으면 R에 대한 민감도가 O(k)로 소멸). 한계로 기록.

## 재현

```bash
python -m src.calibrate --config configs/stage_a/sio2-freeze.yaml         # phase 0+1 (~1h CPU)
```

동일 — phase 2가 실제 세션 중단 후 step 1500에서 재개돼 무중단과 동일 궤적으로 완주.

## 한계·후속

- **Si k(λ)의 λ > 450 nm 구간은 약식별** — 물리 디코더 용도(R 재구성)에는 영향이
  없지만(민감도가 작다는 것 자체가 이유), 이 곡선을 재료 물성 주장으로 쓰면 안 된다.
- 잔여 매끈한 모델 오차 RMS ~0.0033 (lag-1 자기상관 +0.127) — 후보 원인은 SiO₂
  게이지의 문헌값 근사 오차, 층 k=0 가정(284 nm 부근 SiN 흡수), 계면 효과.
  Stage B에는 σ 대비 무시 가능한 수준으로 판단.
- 채널별 미세조정(phase 2)은 채널 수만큼 자유도를 쓰므로 "물리 곡선"의 매끈함을
  파라미터화로 강제하지 않는다 — 결과 곡선이 매끈하게 나온 것(fig_stage_a1)은
  데이터가 그렇게 요구했기 때문이며, 이는 오히려 캘리브레이션의 신뢰 근거다.
